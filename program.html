MODULE 1

Foundations of Image Segmentation

TOPICS Hours
Introduction to digital image processing, image representation and fundamental image segmentation techniques, including thresholding, edge-based, region-based and morphological approaches.
SPEAKERS: Dr. P. Balasubramaniam,
Dr. Varun P Gopi
06
MODULE 2

Classical Clustering and Fuzzy-Based Segmentation

TOPICS Hours
CLASSICAL CLUSTERING AND FUZZY-BASED SEGMENTATION
Fundamentals of clustering and fuzzy set theory, mathematical approaches to clustering-based segmentation, hard and soft clustering methods, and their applications in image segmentation.
06
MODULE 3

Transformer Fundamentals for Computer Vision

TOPICS Hours
TRANSFORMER FUNDAMENTALS FOR COMPUTER VISION
Introduction to transformer architectures, attention mechanisms, positional encoding, encoder-decoder frameworks and their applications in computer vision.
03
MODULE 4

Deep Learning Foundations for Image Segmentation

TOPICS Hours
DEEP LEARNING FOUNDATIONS FOR IMAGE SEGMENTATION
Fundamentals of deep learning for image segmentation, convolutional feature learning, encoder-decoder frameworks, semantic segmentation architectures and learning-based approaches to image segmentation.
03
MODULE 5

Advanced Image Segmentation

TOPICS Hours
ADVANCED IMAGE SEGMENTATION
Advanced approaches to image segmentation, including attention-based and transformer-based methods, foundation models, prompt-based segmentation and emerging developments in image segmentation.
06
MODULE 6

Object Detection and Related Vision Tasks

TOPICS Hours
OBJECT DETECTION AND RELATED VISION TASKS
Fundamentals of object detection, object localisation, bounding box prediction, detection architectures, evaluation measures and their applications in computer vision.
