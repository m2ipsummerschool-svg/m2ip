SUMMER SCHOOL WEBSITE TEMPLATE
================================

Files:
- index.html       Home / overview
- register.html    Registration categories and fee table
- speakers.html    Speaker profiles
- program.html     Multi-day programme schedule
- symposium.html   Co-located symposium
- resources.html   Tutorials, videos and papers
- awards.html      Awards and certificates
- logistics.html   Venue, travel and accommodation
- sponsors.html    Sponsors and partners
- people.html      Organising committee
- assets/style.css Shared responsive styling

HOW TO USE
1. Extract the ZIP file.
2. Open index.html in a browser to preview.
3. Edit each HTML file and replace sample content in square brackets.
4. Update dates, fees, registration links, speaker details, images, contacts and institution identity.
5. Keep the assets folder alongside the HTML files.
6. Upload the entire folder to your web hosting server.

This is an original editable starter template based on the section structure of the reference website.
It does not copy the original site's source code, images, branding or exact design. All sample event
details are placeholders and must be replaced with verified information.
